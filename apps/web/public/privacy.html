Конфиденциальность игры «Скажи наоборот»

Игра использует микрофон только после явного разрешения пользователя.

Голосовые записи

Записанный звук, его перевёрнутая версия и повторная попытка обрабатываются локально в браузере. Аудиофайлы и PCM-данные не отправляются на backend игры и не сохраняются в базе данных.

Техническая аналитика

Для улучшения игры могут фиксироваться обезличенные технические события: открытие игры, этап прохождения, итоговый игровой балл, источник перехода, создание ссылки-приглашения и переход в EasySong. Содержание произнесённых фраз не передаётся в аналитику.

Telegram Mini App

При запуске внутри Telegram сервер может проверять подпись Telegram initData для подтверждения подлинности запуска. Идентификатор пользователя не используется как публичный игровой профиль.

Хранение на устройстве

Local Storage может временно использоваться для очереди технических событий при потере сети. Голосовые записи в Local Storage не сохраняются.
